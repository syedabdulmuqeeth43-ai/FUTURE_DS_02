# Task 2 – Customer Retention & Churn Analysis Dashboard

## Overview
This project focuses on customer churn behavior and retention performance. The dashboard was created to understand why customers leave and what factors improve retention.

## Tools Used
- Power BI
- Excel / CSV Dataset
- Data Cleaning
- DAX Measures

## Dashboard Features
- Total Customers KPI
- Customers Lost KPI
- Churn Rate KPI
- Retention Trend
- Churn by Contract Type
- Churn by Payment Method
- Customer Segmentation
- Interactive Filters

## Key Insights
- High churn found in month-to-month contracts.
- Electronic check users showed higher churn.
- Long-term customers had stronger retention.

## Outcome
Developed a dashboard that helps businesses reduce churn and improve customer loyalty.
